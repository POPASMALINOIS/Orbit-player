# Historial de cambios

## 0.2.0 — PWA personal

- Orbit Player pasa a desarrollarse principalmente como PWA para uso personal.
- Importación y reproducción persistente de MP3 desde Archivos.
- Volumen interno real mediante Web Audio y `GainNode`.
- Botones laterales para retroceder o avanzar 10 segundos.
- Pulsación mantenida para rebobinado y avance continuos.
- Lectura de título, artista, álbum y portada incrustada en etiquetas ID3 de archivos MP3.
- Portadas y metadatos guardados localmente mediante IndexedDB.
- Renovación automática de la caché y publicación en GitHub Pages.

## 0.1.0 — MVP nativo

- Interfaz original inspirada en reproductores clásicos.
- Rueda circular táctil con navegación angular y respuesta háptica.
- Importación de audio y vídeo desde Archivos.
- Biblioteca local persistente.
- Reproducción mediante AVPlayer.
- Audio en segundo plano y controles multimedia del sistema.
- Favoritos y reproducción de vídeo a pantalla completa.
- Proyecto reproducible con XcodeGen y validación automática en GitHub Actions.
